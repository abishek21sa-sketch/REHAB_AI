# Security Policy

REHAB AI v0.1.0 is a research/portfolio build and should only use synthetic or appropriately de-identified data. Do not expose it to the public internet with patient data.

A production deployment must add identity and access management, role-based authorization, encrypted transport and storage, secrets management, structured audit trails, retention controls, backup/recovery, dependency scanning, vulnerability management, and the privacy/security controls required by the intended jurisdiction and deployment context.
